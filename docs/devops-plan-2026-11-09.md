поручил выбрать и выполнить DevOps доработки и внести результат в трекер.

Старые локальные файлы от 27 октября не заменяют текущий код команды.

## Решение

Используем фактический стек: FastAPI/Python 3.12, PostgreSQL 16, React/Vite
в client и Windows-агент. Прежнее предложение Java не переносится в этот код.
Развиваем имеющиеся Compose, CI и backend/scripts/backup.py, не создаём
вторую реализацию приложения или резервного копирования.

Альтернативы: оставить отдельные dev-серверы — не проверяет общий запуск;
перестроить backend под Java — выходит за DevOps и дублирует работу команды.
Выбран общий локальный стенд с Caddy и проверками действующего Python приложения.

## Границы

Функции регистрации и интерфейса, бизнес-логика агента и физическая печать не
меняются. Docker daemon на текущем компьютере пока не обнаружен: локальные
проверки не выдаются за запуск контейнеров. Итоговый статус должен опираться
на результаты тестов и CI, а не на запись в плане. В YouGile будут внесены
фактически выполненные результаты и оставшиеся ограничения.
