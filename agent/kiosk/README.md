# Киоск и агент печати на Windows 11

Нужен выделенный терминал с Windows 11 Pro, Enterprise, Education или IoT Enterprise, актуальным Microsoft Edge, локальным администратором и очередью XP-360B. Скопируйте скрипты и проверенный `regsys-agent.exe` в каталог, доступный для изменения только администратору. Используйте DNS-имя HTTPS из инструкции [развёртывания](../../deploy/README.md). Маршрут терминала в клиенте — `/`.

## Подготовка

1. Включите питание XP-360B, затем подключите USB. Проверьте имя очереди Windows и возможность печатать в неё у `LOCAL SERVICE`. Печать агента работает через отдельную учётную запись, поэтому права вошедшего администратора недостаточны.
2. Для локального CA установите доверие к его публичному корневому сертификату в хранилище компьютера. Передайте тот же публичный PEM-файл агенту через `-CaFile`. Для публичного CA этот параметр можно опустить.
3. Отключите Punto Switcher и автоматическое переключение раскладок на выделенной машине. Подготовьте отдельные токены принтера и терминала. Токен агента вводится в защищённом приглашении, токен терминала передаётся штатным механизмом фронтенда. Не добавляйте реквизиты в URL, аргументы планировщика и скрипты.

## Установка и проверка

Предварительный просмотр выводит параметры агента и XML Assigned Access без применения настроек.

```powershell
.\Set-PrintAgent.ps1 -AgentExe C:\RegsysSetup\regsys-agent.exe -ServerUrl https://terminal.example.test/ -PrinterName XP-360B -CaFile C:\RegsysSetup\regsys-root.crt
.\Set-TerminalKiosk.ps1 -TerminalUrl https://terminal.example.test/
```

В повышенном 64-разрядном Windows PowerShell 5.1 выполните первую команду с `-Action Install`. Она установит задачу `Regsys Print Agent` на запуск при старте Windows от `LOCAL SERVICE`. Исполняемый файл, конфигурация и CA защищены ACL. Содержимое INI доступно администраторам, SYSTEM и процессам под LOCAL SERVICE. Не используйте эту учётную запись для посторонних служб на терминале. Агент пишет журнал в отдельный каталог `runtime`. Планировщик игнорирует повторный запуск уже работающей задачи. Повторный Install с теми же файлами и параметрами оставляет работающий агент запущенным. Для смены EXE, CA, токена или параметров используйте Remove и новый Install в окно обслуживания.

Для установки Assigned Access выполните вторую команду с `-Action Install` из сеанса Windows PowerShell под `SYSTEM`. Microsoft описывает локальный запуск через Sysinternals PsExec. Скрипт не меняет пароль администратора и не перезагружает компьютер. После проверки конфигурации перезагрузите выделенный терминал, убедитесь, что Windows автоматически вошла в ограниченную учётную запись, а Edge открыл терминал. Для обслуживания используйте `Ctrl+Alt+Del` и вход под администратором. Политики Edge действуют на всём выделенном компьютере.

Проверьте, что посетитель не может запустить другое приложение, открыть сторонние сайты, страницу входа или панель и что запрос терминала к API панели отклоняется. Убедитесь, что у задачи агента одна активная копия и есть heartbeat. Выполните пробную печать, временно разорвите связь и проверьте восстановление работы без перезапуска. При отсутствии подтверждения регистрации наклейка не должна выходить. Экран должен показать «Нет связи с сервером. Обратитесь к стойке регистрации» и перестать принимать коды.

Текущий фронтенд читает токен терминала из `localStorage`. В режиме Edge kiosk используется InPrivate, поэтому требуется механизм повторного получения токена при старте сессии. До его появления автоматическая загрузка рабочего терминала остаётся открытым критерием. Проверьте согласованный текст офлайн-экрана при приёмке фронтенда.

## Отмена

1. Из сеанса `SYSTEM` выполните `.\Set-TerminalKiosk.ps1 -Action Remove`. Скрипт снимает только свою конфигурацию и свои значения политик. Завершите сеанс киоска или перезагрузите терминал.
2. Из повышенного окна администратора выполните `.\Set-PrintAgent.ps1 -Action Remove`. Задача будет остановлена и удалена, файл с токеном удалён. Журнал и бинарник остаются в `%ProgramData%\RegsysKioskAgent`. Отзовите токены отключённого устройства в панели.
3. Доверие CA и настройки раскладки возвращает администратор согласно правилам площадки.
